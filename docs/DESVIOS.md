# Desvios de perfil

Uma linha por fatia que foi **planejada** num perfil e **rodou** em outro.
Silêncio é o caso comum e está certo — não escreva linha quando não houve
desvio. Sem este arquivo a tabela de perfis do `docs/ROADMAP.md` é opinião
congelada: nada registra quando ela errou, e ela nunca aprende.

Formato:

```
AAAA-MM-DD | C4 | planejado: sonnet/medium | usado: opus/high | motivo em meia linha
```
