# Simulated datasets

Generated by the `simulation/` package — see `simulation/config.py` for every
parameter (the single source of truth) and `docs/PLAN.md` §3 for the design
rationale. **Nothing here is real data**: fully simulated, seeded, and
reproducible.

## Regenerate

```bash
python -m simulation.generate          # all seeds (101-105)
python -m simulation.checks            # sanity gate (must exit 0)
```

Determinism contract: same seed + same generator version (see
`GENERATOR_VERSION`) → byte-identical CSVs (checked by C6 in
`simulation/checks.py`).

## Generating process (summary)

- 8 geos × 156 weeks (window 2023-01-02 … 2025-12-28, Mondays), plus 26
  warm-up weeks simulated for adstock burn-in and dropped from outputs.
- `revenue = baseline + control effect + Σ media contributions + noise`
  (additive, matching both tools' regression form).
- Baseline: population-share-scaled level × linear trend (+10% over the
  window) × yearly seasonality (2 harmonics) × holiday uplifts (Black Friday,
  Christmas, mid-May event weeks).
- Media, per channel: national spend (always-on base + flights + lognormal
  wiggle) → geo allocation (population share × AR(1) tilt) → impressions
  (spend / CPM with fixed geo factors and weekly noise; linear in spend) →
  **geometric adstock** (normalized, max lag 13; Jin et al. 2017) → **Hill
  saturation** → β per capita × population.
- tv and ooh share 75% of their flight calendars (shifted 0–1 weeks) and have
  correlated spend wiggle — the deliberate multicollinearity dial (realized
  tv–ooh spend correlation ≈ 0.34–0.61 across seeds).
- Control: one national AR(1) `competitor_index` (mean 100) with a negative
  revenue effect, broadcast to all geos.
- Noise: weekly iid Gaussian per geo, sd = 7% of the geo baseline level.
- True channel parameters (adstock retention, Hill K and S, target ROI) are in
  `simulation/config.py`; βs are calibrated so the full-window counterfactual
  ROI hits the targets exactly. One channel (tv) is deliberately S-shaped
  (S = 2); ooh is deliberately low-ROI with above-effect spend share (the
  DECOMP.RSSD probe); adstock retentions sit inside Robyn's recommended
  hyperparameter bounds per channel type (PLAN D5).

## Ground truth (`ground_truth.json` per seed)

Counterfactual definitions (PLAN D7): **true ROI** = window-total incremental
revenue with the channel zeroed out (the model is additive, so no cross
terms) / window spend; **true mROI** = +1% spend perturbation; **response
curves** = incremental revenue at spend multipliers 0–3×. Note tv's true
mROI > ROI: an S-shaped curve operating below its inflection point — that is
intentional, not a bug.

Known media variance share of national revenue: ~0.23–0.35 across seeds
(reported per seed in `variance_decomposition`).

**Per-channel signal-to-noise (C7 gate, WARN only):** the variance share above
is a *total*, and it hid that two of the five channels carry almost no
recoverable signal. `simulation.checks` prints, per seed, each channel's
signal-to-noise (std of true national contribution / std of national revenue
noise) and warns below a floor of 0.15. v1 has ooh (~0.10–0.12) and display
(~0.09–0.11) under that floor in every seed — confirmed unrecoverable by the
oracle in `analysis/ORACLE.md`, not just noisy. Any future scenario should run
`python analysis/oracle.py` before spending GPU time on it; see that file for
what it measures and why C7 is only a cheap proxy for it.

## Files per seed (`data/sim/seed<NNN>/`)

| file | grain | consumer |
|---|---|---|
| `geo.csv` | geo × week | Meridian geo arm |
| `national.csv` | week (geo-aggregated) | Meridian national arm |
| `robyn.csv` | week, Robyn column convention (`DATE`, `<ch>_S` spend, `<ch>_I` impressions) | Robyn |
| `ground_truth.json` | — | scoring only — **never** shown to the tools |

Columns (geo/national): `date, geo?, population, revenue, competitor_index,
<ch>_spend, <ch>_impressions` for ch in tv, ooh, social, display, search.

## Deliberate limitations (disclosed, PLAN §5)

Spend is exogenous (no demand-chasing budgets — the *easy* regime for MMM);
true parameters are constant over time; no reach/frequency channels; no
synergies; impressions are rounded to integers and money to cents (negligible
vs. the stored truth).
